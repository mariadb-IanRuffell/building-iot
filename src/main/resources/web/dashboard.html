Send your own data

Any gateway can POST one reading or an array of readings:
curl -X POST http://localhost:8080/api/ingest \
  -H 'Content-Type: application/json' \
  -d '[{"sensorId":"TEMP-F2-W","value":23.4},
       {"sensorId":"OUT-TEMP","value":7.9,"ts":"2026-11-13T09:30:00Z"}]'
Readings flow HTTP → validate → GridGain Data Streamer → SENSOR_READING_HOT (memory, 24 h), SENSOR_READING (disk, all history) and SENSOR_LATEST. Click any sensor row to chart its stored history.
